Kawaicord 1.5.0 adds macOS support and an in-app update flow.

- Universal macOS DMG for Apple Silicon and Intel, with Shelter and switchable Vencord/Equicord bundled.
- Windows updates apply silently from Kawaicord settings; no installation wizard is needed for subsequent updates.
- macOS updates use a verified ZIP and a detached app-replacement helper, with automatic rollback if the replacement fails to start.
- Updates preserve the user profile and wait for an explicit Restart and update action.
- macOS application menu, Dock unread badges, and menu-bar tray support.

For a first Mac installation, open the DMG and drag Kawaicord to Applications. macOS builds are ad-hoc signed and are not notarized; first-launch Gatekeeper approval may be required. Windows builds remain unsigned.
